# Minimal vs Pro

Yantra Launcher is available in two flavors. Minimal keeps the launcher small and focused. Pro brings the larger toolbox for people who want the terminal to handle nearly everything short of making coffee.

## Minimal

Minimal includes the core launcher and everyday commands such as:

```text
launch help community call bluetooth flash alias weather search username time
settings sysinfo pro quote text tts info uninstall list music backup unalias
history location lock clear reset cmdrequest feedback support exit
```

## Pro

Pro includes the Minimal commands and adds the broader command set, including themes, notes, AI, file navigation, scripts, Termux, media controls, automation, calculators, weather extras, and other utilities.

The exact command list is always the most reliable source: run `help` inside the installed build. If a command is not listed there, that build does not currently expose it.

The Pro version is released as a paid app on Play Store to support continued development. It is not a different command language, it is the fuller Yantra toolbox.
